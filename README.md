# 📚 Rama de Documentación - Proyecto Perle Noire  

## 📝 Descripción  
Esta rama está destinada exclusivamente a la **documentación oficial** del proyecto de Ingeniería de Software desarrollado para **Perle Noire**, empresa de servicios de belleza que busca optimizar sus procesos administrativos mediante un sistema de información integral para:  
- Agendamiento de citas  
- Gestión de facturación  

## 📌 Propósito de la Rama  
El objetivo principal de esta rama es:  
- Centralizar todos los documentos relacionados con el **análisis, diseño, desarrollo y gestión** del proyecto.  
- Mantener un historial organizado de los avances documentales.  
- Servir como soporte teórico y técnico para la implementación del sistema.  

## 📂 Contenido de la Rama  
En esta rama se incluirán documentos tales como:  
- Documentación de requerimientos  
- Diagramas de análisis y diseño  
- Planificación del proyecto  
- Informes de avances  
- Manuales técnicos y de usuario  
- Minutas de reuniones (si aplica)  

## 🔗 Relación con otras Ramas  
- La rama **main** contendrá la versión estable del sistema.  
- La rama **develop** concentrará el desarrollo del software.  
- La rama **documentation** (esta) será el repositorio oficial de todos los archivos de soporte y documentación.  

✍️ **Nota:** Cualquier cambio en la documentación debe realizarse en esta rama, para asegurar la trazabilidad y consistencia del proyecto.
