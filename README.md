# 🚀 Rama de Producción - Proyecto Perle Noire  

## 📝 Descripción  
Esta rama contiene la **versión estable y oficial** del sistema de información desarrollado para Perle Noire.  
Aquí se almacena el código ya validado, probado y aprobado, listo para ser utilizado en el entorno real por la organización.  

## 🎯 Objetivo  
- Garantizar que la versión publicada sea estable y confiable.  
- Servir como la base oficial del sistema en operación.  
- Proporcionar una referencia del estado más actualizado y validado del proyecto.  

## 📂 Alcance de la Rama  
La rama de producción incluye únicamente:  
- Código validado y probado.  
- Configuración lista para despliegue en servidores de la empresa.  
- Documentación mínima necesaria para la instalación y ejecución.  

## 🔗 Relación con otras Ramas  
- Recibe cambios únicamente desde la rama **testing** (una vez aprobados).  
- Es la rama de referencia para el entorno real de la organización.  

---

⚠️ **Importante:**  
Los cambios directos en esta rama están **prohibidos**. Solo se permiten actualizaciones provenientes de **testing** tras pasar el ciclo de pruebas.
