# 🧪 Rama de Pruebas - Proyecto Perle Noire  

## 📝 Descripción  
Esta rama está destinada a la **ejecución y validación de pruebas** sobre las funcionalidades desarrolladas en el sistema de información de Perle Noire.  

Aquí se evaluará que cada módulo cumpla con los requerimientos establecidos antes de ser integrado a la rama de producción.  

## 🎯 Objetivo  
- Probar nuevas funcionalidades en un entorno controlado.  
- Detectar y corregir errores antes de la liberación.  
- Validar la estabilidad y desempeño del sistema.  

## 📂 Alcance de las Pruebas  
En esta rama se realizarán pruebas de:  
- ✔️ Funcionalidad  
- ✔️ Integración  
- ✔️ Rendimiento  
- ✔️ Seguridad  
- ✔️ Experiencia de usuario  

## 🔗 Relación con otras Ramas  
- Los cambios llegan desde la rama **develop** para ser probados.  
- Una vez validados, se envían a la rama **production** para su despliegue final.  

---

✍️ **Nota:** Ningún cambio debe pasar a producción sin haber sido previamente probado y validado en esta rama.
